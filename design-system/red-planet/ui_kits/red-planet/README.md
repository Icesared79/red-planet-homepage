# Red Planet website UI kit

Recreation of the Red Planet homepage ("Red Planet - Registry") composed entirely from system components at comfortable density.
Built from a screenshot of the page; the page itself was not modified.

- `index.html` — full homepage, sticky TopBar navigation scrolls to sections, Coverage pill tabs switch market lists.
- `Sections.jsx` — Hero, MissionControl, WhyDifferent, HowItWorks, Coverage, Contact.
- `App.jsx` — page assembly.

Band rhythm: page → forest → sage → forest → paper → forest. Bands are 18px-radius Sections separated by 8px of page.
The homepage's "Built on Atlas" product section was removed: Atlas is Red Planet's only product. The Red Planet mark is rendered as plain type until a logo file is supplied.
