A single important number, set in mono so digits align and read as data.

```jsx
<Metric size="xl" label="Verified property and data records" aside="9 hours ago" value="502,392,645" meta="+275.5M archived · 777.9M all-time" />
<Metric size="m" label="Pipeline steps completed" value="126 of 127" />
<Metric size="m" label="Flagged for retry" value="1" tone="attention" />
```

- xl/l for Red Planet hero cards; m/s for Atlas panels and KPI strips.
- Use full numbers with thousands separators on Red Planet; abbreviate (777.9M) only in meta lines or tight Atlas cells.
