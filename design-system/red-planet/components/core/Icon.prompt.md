Thin-stroke Lucide icon that inherits text color; use for navigation, toolbar actions and inline affordances — never as decoration in editorial copy.

```jsx
<Icon name="database" />
<Icon name="triangle-alert" size={14} label="Needs attention" />
```

- Size follows density automatically via `--icon-size` (20 / 16).
- Keep stroke 1.5 so icons match the 1px rule language.
