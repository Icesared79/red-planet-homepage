Monospace section label placed directly above a display headline; one per section.

```jsx
<Eyebrow index={1}>What we do</Eyebrow>
<h1 className="rp-display-xl">Deeper Data Intelligence.</h1>
```

- Sentence case, never uppercase. Numbering is sequential down the page.
- In Atlas (`data-product="atlas"`) it turns grey automatically; do not force `tone="accent"` there.
